## Este repositorio

El sitio corporativo bilingüe (ES en `/`, EN en `/en/`), generado como HTML estático sin dependencias de ejecución.

```bash
node build.mjs        # genera dist/
node validate.mjs     # SEO, hreflang, enlaces, CSP, accesibilidad básica
node scripts/qa.mjs   # QA en navegador (Playwright): responsive, consola, comportamiento
```

## Principio editorial

Todo lo publicado es verificable. Cada proyecto y producto indica su estado (**disponible**, **en desarrollo**, **planificado**) y la evidencia que lo respalda. No se publican clientes, métricas, certificaciones ni capacidades que no se puedan demostrar.
